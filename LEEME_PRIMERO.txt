🚀 INICIO RÁPIDO (3 PASOS)
═══════════════════════════════════════════════════════════════

OPCIÓN 1 - Automático (Recomendado):
   ▶ Haz doble clic en: run.bat
   ▶ ¡Listo! La app se abrirá automáticamente

OPCIÓN 2 - Manual:
   1. Abre PowerShell o CMD en esta carpeta
   2. Ejecuta: python -m venv venv
   3. Ejecuta: venv\Scripts\activate
   4. Ejecuta: pip install -r requirements.txt
   5. Ejecuta: python app.py
   6. Abre tu navegador en: http://localhost:5000

═══════════════════════════════════════════════════════════════
❓ SOLUCIÓN DE PROBLEMAS
═══════════════════════════════════════════════════════════════

Problema: "Python no se reconoce"
Solución: Instala Python desde python.org

Problema: "No se puede activar venv"
Solución: Ejecuta: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

Problema: Las imágenes no cargan
Solución: Verifica tu conexión a internet

Problema: Error al iniciar Flask
Solución: Ejecuta: pip install --upgrade flask
