## 🚀 Cómo Iniciar

### Método 1: Automático
```bash
# Simplemente ejecuta:
run.bat
```

### Método 2: Manual
```bash
# 1. Crear entorno virtual
python -m venv venv

# 2. Activar entorno
venv\Scripts\activate

# 3. Instalar dependencias
pip install -r requirements.txt

# 4. Ejecutar aplicación
python app.py
```

### Resultado
```
La aplicación estará disponible en:
http://localhost:5000
```
